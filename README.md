# explain-srl-by-training-data
A practical approach to explain SRL decisions through label-centric retrieval of training examples and influence scoring.
This repository provides the implementation of a technique for training-data attribution in Semantic Role Labeling (SRL) models that identifies influential training tokens by modeling their relationship to the label-wise centroid in the representation space, enabling post-hoc retrieval of training examples without modifying or retraining the model.
